# Salt Bread & Spice

A responsive restaurant website built with HTML and CSS.

## Files
- `index.html` — website content and page structure
- `style.css` — layout, colors, typography, and responsive styling
- `images/` — put your image files here when their paths in `index.html` begin with `images/`

## Add your photos
The HTML uses the image filenames from your original code. Add those image files to this project, keeping the same names and folder paths. For example:
- `BakeandSaltfish.jpg` belongs in the project root.
- `images/sancocho.jpg` belongs inside the `images` folder.

If an image does not appear, check that its filename (including spaces, capitalization, and `.jpg`/`.png`) matches the HTML exactly.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, the image files, and this README.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Wait for GitHub Pages to publish your site.

The contact form currently uses a `mailto:` action, so it opens the visitor's email app. A static GitHub Pages site does not process or store form submissions by itself.

## Before publishing
Review the restaurant address, phone number, email address, hours, and menu details. Replace any sample contact information with the correct business information.
